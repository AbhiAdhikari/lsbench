# Maintainer issues — drafts

Fairness rule: issues with reproductions are filed **before** scores are
published, and maintainer responses are recorded in `servers.yaml`. These are
the drafts. File them from your own GitHub account, then set
`maintainer_notified: true` and paste the response (or "no response after N
weeks") into `maintainer_response`.

Each draft is written to be pasted as-is. Reproductions use only the server's
own tools and public APIs — nothing depends on lsbench.
